環境政策実験

線形の需要・供給と、1単位当たり一定の外部費用を置いた教材用モデル。現実の政策効果を予測するものではない。

このページの数値は説明用の仮想値です。「税を上げれば現実でもこの通りになる」という予測には使えません。

モデル

逆需要を P = a − bQ、企業の限界費用を MC = c + dQ、生産1単位が外部に与える損失を e とする。したがって社会的限界費用は SMC = MC + e。

競争均衡: Q₀ = (a − c) / (b + d)\n社会最適: Q* = (a − c − e) / (b + d)

社会的余剰

需要曲線の下の総便益から、生産費用と環境損失を引いて計算する。税収は社会内部の移転なので、総余剰では別途足し引きしない。

なぜ「政府推定」を分けたか

現実には外部費用の真値を完全には観測できない。そこで真の外部費用と政府推定値を分離し、「推定値に合わせた税」が真の社会最適からずれる場合を触れるようにした。

前提

  • 需要・供給は線形。
  • 外部費用は生産量1単位当たり一定。
  • 技術革新、所得効果、国際取引、分配、公平性は扱わない。
  • 生産上限では割当方法の分配効果を扱わず、総余剰だけを見る。
